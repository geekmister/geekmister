### My inspiration

#### 1. 素材管理

我在做小红书笔记、商品详情时产生了大量的图片、视频等素材，这就涉及到了素材管理，一开始我采用的方式是以笔记和商品这种分类的方式进行管理，但是碰到了大量的素材处于多端、重复、不好查找等问题，所以我想做一款专门的素材管理工具来解决这类的问题！市面上虽然有，但是要收费且自己的需求有些不能满足，还有不开源（如果开源会收货更多的 idea，让素材管理功能变得丰富多样）

#### 2. 小红书分析

我在做小红书运营时，发现我想知道自己的账号出现了哪些问题？同类账号都有哪些？账号权重是多少？都有哪些竞品？是否可以做一些竞品分析？所以基于这些我想做一款小红书的全面分析，但是我不准备把这个开源，采取的是收集大家的需求我来实现。不开源的原因是这款软件可能会进行商业化！

#### 3. 个人云存储

手机里有大量照片视频或者文件，我又有多个手机和 Pad，用市面上的各类云盘不是收费开会员还是开会员，如果这样那不如把钱交给 COS，做一套个人云存储服务
